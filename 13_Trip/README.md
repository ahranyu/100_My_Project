# Travel Cities Dashboard

![Dashboard](image/dashboard.mp4)

## Intro

In this project, I created a dashboard using **Power BI**.
I obtained the dataset from [kaggle: Worldwide Travel Cities (Ratings and Climate)](https://www.kaggle.com/datasets/furkanima/worldwide-travel-cities-ratings-and-climate?resource=download).

The dashboard can be used to explore potential travel destinations by selecting a country on the map. The final page displays details about the city, including budget rating, recommended duration of stay, and average temperature.

I focused on creating an easy-to-navigate interface, and also I practiced data modeling using **Power Query**.

Check out the file: [Dashboard](13_Trip\Trip_Dashboard.pbix)

## Skills I Used

This project was built using Power BI.
Here's what I practiced:

- **Data Transformation with Power Query:**
    Using Power Query, I cleaned and prepared the raw data for analysis. I changed data types, transformed values, and created new columns such as `month name` and extracted the average monthly temperature.
- **Data Modeling:** I created a star schema by separating temperature, ideal duration, and thematic rating data. 
- **Implicit Measures:** Created a measure `Count of Destination`.

- **Dashboard Design:** Designed an intuitive and easy-to-navigate interface using a map chart. By selecting a point on the map, the user can check the average monthly temperature, thematic ratings, budget and a brief description of the city.
- **Visualisations:**
    - **Map Charts:** Used map charts to show the regions, countries and cities. This helps users easily understand the location of the destination.
    - **Line Charts:** Showed the average monthly temperature of the selected destination. 
    - **Gauge Charts:** Visualised gauge of thematic ratings.
    - **Cards:** Showed country name, ideal duration, budget score and a short description of the city.
- **Interactive Reporting:**
    - **Buttons:** Implemented buttons to allow users to easily navigate between pages.
    - **Drill-Through:** Enabled drill-through function to navigate from region to country, and from country to city.


## What I Learned

Throughout this project, I learned data handling and visualisation using Power BI.

-**Power Query:** Utilised Power Query to create new tables to build the star schema. I also conducted transformations and added new columns, changed data types and pivoted the data for analysis.

-**Data Preparing:** From the dataset, I extracted desired data such as average temperature and month, also created a new column `month_name` for graph visualisation. Separated the thematic rating and calculated the average rating.

-**Visualisation:** To design an easy and intuitive layout, I used map charts for navigation and set drill-through for deeper exploration. I also included relevant information in the tooltips for more context. 

## Conclusion

This World Wide Travel City Dashboard provide a quick overview of the selected city including budget level, ideal duration, location and monthly temperature.
By completing this dashboard, I enhanced my data handling skills with Power Query, specifically in data modeling and transformation. Additionally, I improved my visualisation skills by using various charts in Power BI.
